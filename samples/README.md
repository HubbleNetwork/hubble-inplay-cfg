# Hubble IN100 Sample Configurations

All samples in this directory share:

- TX power (+4dBm)
- Rotation exponent (15, ~9hrs)
- Key (0's, you will need to set a valid key)

To use them, you will need to provide your key when programming your device. You can do this in the CLI tool by using the `-k0`/`--key0` argument or by manually setting your key in the NanBeacon Config Tool under Global Settings -> Keys -> Key 0.
